# 사용자 비밀번호 일괄 초기화 (`ZBC_USER_PWD_RESET`)

여러 대화형 사용자의 초기 비밀번호를 한 번에 설정하는 ABAP 리포트입니다.
**테스트 실행으로 대상을 먼저 확인한 뒤, 실행을 한 번 더 눌러야 실제로 변경**되는 2단계 구조입니다.
비밀번호 오류로 잠긴 계정은 잠금도 함께 해제합니다.

- 소스: [zbc_user_pwd_reset.abap](zbc_user_pwd_reset.abap) (단일 리포트, Include·화면 페인터·GUI status 없이 동작)
- 대상 릴리스: SAP NetWeaver 7.40 이상 / S/4HANA (ABAP 7.4x 문법 사용)

## 화면 흐름

```text
[선택 화면]
  사용자       [USER01   ] [→]   ← 단일값 포함/제외, F4: ID·이름·사용자그룹·효력종료일
  새 비밀번호  [**********]
        │ F8
        ▼
[결과 화면 - 테스트]   SID/클라이언트 비밀번호 초기화 (테스트)
  (테스트) 총 5명 중 변경 대상 3명 / 제외 2명 / 잠금 해제 예정 1명
  ┌───────────────────────────────────────────────────────────────┐
  │상태│사용자 │이름  │사용자그룹│잠금            │효력기간│메시지              │
  │ 🟢 │USER01│홍길동│SUPER    │비밀번호 오류 잠금│        │(테스트) 잠금 해제 예정│
  │ 🟡 │USER02│김철수│SUPER    │관리자 잠금      │        │관리자 잠금은 해제 안 함│
  │ ⚪ │DDIC  │      │         │                │        │보호 대상 계정이라 제외 │
  └───────────────────────────────────────────────────────────────┘
        │ 실행(F8) → 확인 팝업 "N명의 비밀번호를 실제로 변경합니다"
        ▼
[결과 화면 - 실행 결과]
  총 3명 변경 완료 (잠금 해제 1명) / 실패 0명 / 제외 2명
```

신호등: 🟢 변경 대상·성공 / 🟡 변경되지만 확인 필요(관리자 잠금, 효력기간 밖) / 🔴 오류 / ⚪ 제외

## 처리 규칙

| 항목 | 동작 |
|---|---|
| 대상 | 현재 클라이언트의 대화형 사용자(유형 A). 단일값 포함 − 제외, 범위·패턴 입력 불가 |
| 보호 계정 | 실행자 본인, `SAP*`, `DDIC`, `SAPCPIC`, `EARLYWATCH`, `TMSADM` 자동 제외 |
| 권한 | 사용자 그룹별 `S_USER_GRP` 활동 05 사전 확인, 실제 변경 시 BAPI가 추가 검사 |
| 비밀번호 | `BAPI_USER_CHANGE`로 **초기 비밀번호** 설정 → 다음 로그인 시 사용자가 변경 |
| 잠금 | 비밀번호 오류 잠금(`USR02-UFLAG` 128)만 `BAPI_USER_UNLOCK`으로 해제. 관리자 잠금(32/64)은 유지 |
| 효력기간 | 종료일 경과·시작일 이전이면 표시만 함(자동 연장하지 않음) |
| 트랜잭션 | 사용자별 커밋. 오류 시 해당 사용자만 롤백, 커밋 결과가 불확실하면 이후 처리 중단 |
| 재검사 | 실행 직전에 대상 상태를 다시 읽어 테스트 이후 바뀐 잠금·권한을 반영 |
| 백그라운드 | 지원하지 않음 (화면 실행 전용) |

## 보안 설계

- 소스에 비밀번호 기본값이나 상수를 두지 않습니다. 입력값은 실행 후 화면·변수에서 지웁니다.
- 비밀번호 테이블을 직접 갱신하지 않고 표준 BAPI만 사용합니다.
- 결과 목록과 메시지에 비밀번호를 표시하지 않습니다.
- 실제 변경 전에 SID/클라이언트와 인원수를 확인 팝업으로 보여 줍니다.

## 구현 포인트

- **BAPI 테이블 파라미터 타입**: `BAPI_USER_CHANGE`의 `RETURN`에 `WITH EMPTY KEY` 테이블을 넘기면 `PERFORM_CONFLICT_TAB_TYPE` 덤프가 납니다. 기본 키 standard table(`TYPE STANDARD TABLE OF bapiret2`)을 사용합니다.
- **결과 화면**: `SELECTION-SCREEN BEGIN OF SCREEN 200`으로 코드에 정의한 화면에 docking container + `CL_SALV_TABLE`을 붙였습니다. 별도 Dynpro나 GUI status 없이 표준 실행(F8)/뒤로(F3)로 2단계 흐름을 만듭니다.
- **입력 제한**: `SELECT_OPTIONS_RESTRICT`로 다중 선택을 단일값(EQ) 포함/제외로 제한합니다.
- **선택 텍스트**: `INITIALIZATION`에서 `%_S_USER_%_APP_%-TEXT`에 라벨을 넣어 텍스트 요소 없이 표준 배치를 유지합니다.

## 설치

1. SE38에서 실행 프로그램 `ZBC_USER_PWD_RESET`을 만들고 소스를 붙여 넣습니다.
2. 패키지·전송 요청을 지정하고 활성화합니다.
3. 필요하면 T-code를 만들어 권한 롤로 실행자를 제한합니다.

## 테스트 체크리스트

- [ ] 테스트 실행 시 아무것도 변경되지 않는지
- [ ] 보호 계정·없는 사용자·권한 없는 그룹이 제외되는지
- [ ] 비밀번호 오류 잠금 계정이 변경과 함께 해제되는지
- [ ] 관리자 잠금 계정은 잠금이 유지되는지
- [ ] 비밀번호 정책 위반 시 해당 사용자만 오류 처리되는지
- [ ] 실행 후 결과 화면의 인원수가 실제와 맞는지
